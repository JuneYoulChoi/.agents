# ISO/IEC 25010 and 25019 quality-model profile

Authorities: [ISO/IEC 25010:2023](https://www.iso.org/standard/78176.html) and
[ISO/IEC 25019:2023](https://www.iso.org/standard/78177.html).

Use the product-quality model when properties of the product or system are the
evaluation target. Use the quality-in-use model when stakeholder outcomes in a
context of use are the evaluation target. Do not mix either meaning with QA
testing: in this harness `QA` means Quality Attribute and `QAS` means a
measurable Quality Attribute Scenario.

For every selected characteristic or subcharacteristic, record stakeholder and
concern, context, stimulus, expected response, quantitative response measure,
priority/trade-off, responsible architecture element, test/evaluation method,
and evidence. Select only attributes material to the system; a full taxonomy
dump is not a quality plan.

For formal conformance, use the authorized editions and the project's declared
evaluation scope and method. Public metadata and this profile support guidance
or alignment only.
