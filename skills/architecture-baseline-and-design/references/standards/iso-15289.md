# ISO/IEC/IEEE 15289 lifecycle information-item profile

Authority: [ISO/IEC/IEEE 15289:2019 public record](https://www.iso.org/standard/74909.html).

Use this profile when a project or contract needs controlled lifecycle
information items. For every applicable item record purpose, audience,
authority/owner, required content, source evidence, relationships to other
artifacts, format/location, status/version, review/approval, change trigger,
retention/supersession, and sensitivity.

Map this information to the project's existing PRD, SRS, architecture views,
ADRs, plans, test records, manuals, and handoffs rather than creating duplicate
documents solely to match a title. A combined document is acceptable only when
ownership, content coverage, and traceability remain clear.

Formal conformance requires the authorized edition and a documented mapping of
applicable requirements to controlled evidence.
